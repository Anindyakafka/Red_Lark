## Exact credit sources

`studio/render.ts:sceneSvg` always appends a paper-coloured credit strip, clips art above it, and serializes metadata. `studio.tsx` uses that same SVG as its editing canvas, so the strip is visible even on a fresh CC0 design. The remix loader also attaches credit to each layer; `lib/licenses.ts` gathers visible layer credits. `scripts/seed.ts` adds a separate `${slug}-edition` template text layer (`PLACEHOLDER / … / CC0`); existing in-repo `studioLayers` retain it. Exports share `sceneSvg`; PDF properties reference the strip, while PNG currently embeds density but no attribution. Source metadata must survive edits, layer deletion, save/share and exports; do not remove artwork/licence data or regenerate archive downloads.

There is **no crop tool** in the existing code. Pinch listeners are attached only to the SVG; zoom changes paper width without a midpoint anchor, and panning uses scroll offsets that cannot pan a smaller fitted sheet. Layer resize uses world-axis deltas despite rotation. These require real geometry/interaction changes.

## Proposed layout and sequence

1. Separate editing SVG from export SVG; retain project sources, migrate only the known generated edition marker, add configurable export-only attribution (default on for attribution licences, off for CC0) and embedded metadata in all formats.
2. Keep canvas, slim undo/redo/export bar, zoom/fit/pan/snap, and compact option buttons. One labelled, focus-managed overlay drawer at a time; phone bottom sheets; outside/Escape/toggle dismiss. Group text/fonts, colour, layers/transform, images/captions, shapes/effects, paper/background, export/credits and help/project actions without deleting features.
3. Add normalized, non-destructive image crop with eight edge/corner handles, move, ratio lock/presets, numeric keyboard controls and apply/cancel/reset. Use inverse layer transforms for rotated/scaled content.
4. Move Pointer Events to the complete viewport; use one shared zoom/pan transform, midpoint anchoring, wheel/trackpad/space/middle pan and fit/reset. Verify original export dimensions, local drafts, all locales, themes and no-JS Collection.

Human decisions: confirm whether metadata-only attribution is acceptable for each intended distribution when the optional visible credit line is disabled. The UI will warn that metadata can be lost on printing/reposting; default-on credit for attribution licences is the safe default. Native reviewers still need to approve new hi/bn/ml wording (`reviewed:false`). Real-device Safari/Android gestures cannot be certified by desktop emulation.
